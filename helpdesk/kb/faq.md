# Frequently Asked Questions (Seed)

This file is your initial knowledge base. Add entries as you resolve tickets.

## VPN won't connect
- Check network connectivity.
- Verify credentials and MFA.
- Restart VPN client.
- If it still fails, collect logs and escalate with device OS version and client version.

## SSO login fails
- Confirm the user's account is active.
- Clear browser cache or use an incognito window.
- Re-sync time on device and verify MFA app is working.
